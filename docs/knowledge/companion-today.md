## Why this exists

Butter plans several goals each evening, across different projects. The next morning nothing answers the three questions that start the day: what got finished yesterday, what am I focused on in each project, and what is quietly stuck somewhere. The tools that exist each look at one project or one folder at a time, so seeing everything means asking project by project, and work that stalls elsewhere goes unseen — a task finished but never closed, a work session left open for months, a repository with changes nobody committed.

Today puts all three answers on the first screen of the companion, for every project at once, worked out fresh each time it opens — nothing to run by hand, nothing to confirm. It also says plainly which places it could not check, so "nothing outstanding" is something the screen has proven, not assumed.

## Scope

- Yesterday: tasks that changed state and work sessions that ended, across all projects.
- Focus: each project's current focus, by the same rules the per-project focus board uses, side by side.
- Outstanding: stuck tasks, repository state per workspace and untriaged inbox items, per project, with an explicit list of what could not be scanned.

Not in scope: a written or confirmed plan for the day, and Claude working through tasks on its own.
